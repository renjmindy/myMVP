# Chapter 0 | Brain Upgrade: Building Your Prompt Command System

## Chapter Positioning

This is the true starting point of the entire course. Numbering it "Chapter 0" is intentional — it doesn't require you to install anything, just a browser that can open a Claude.ai or Claude Desktop chat box. Before learning to operate any tool, you first learn "how to talk to Claude" — a skill that runs through every hands-on exercise in Chapters 1–7 that follow.

Most people use AI by "asking questions" — whatever comes to mind gets typed in, an answer comes back, and next time you start from scratch figuring out how to phrase it. This chapter teaches something different: upgrading "asking questions" into a "command system" — expressing tasks with a structure that is repeatable, reusable, and upgradable, so that Claude can consistently produce high-quality output every time, rather than leaving it to luck.

By the end of this chapter, learners should be able to:

1. Use a structured Prompt framework to express tasks, replacing fragmented, off-the-cuff questions;
2. Use Artifacts as a collaboration mode, not just "a place where results get generated";
3. Use a knowledge extraction SOP to turn long files, long conversations, and scattered material into structured knowledge;
4. Design role-play instructions for different tasks, so Claude responds from a specific persona/professional perspective;
5. Own a set of five directly reusable universal prompt templates covering the most frequent daily task types.

The "structured expression capability" produced in this chapter is the foundation for all the hands-on work in Chapters 1–7 — Chapter 2's `CLAUDE.md`, Chapter 3's personal content context, Chapter 4's Cowork task descriptions, and Chapter 5's automation script requirement descriptions are, in essence, all concrete applications of this chapter's methodology in different scenarios.

## Learner Prerequisites

- Only a usable Claude.ai or Claude Desktop account is required (browser access is enough) — no software installation or command-line experience is required;
- It's recommended to prepare 1–2 real tasks you've recently wanted AI to help with (writing, summarizing, analysis, etc. all work) — the entire chapter is practiced around real tasks rather than abstract exercises.

## Chapter Deliverables / Success Criteria

After completing this chapter, learners should produce:

- [ ] The ability to independently write a structured Prompt that includes the four elements "Goal, Context, Format Requirements, Constraints";
- [ ] At least one completed hands-on exercise using Artifacts for multi-round iterative collaboration;
- [ ] One completed real knowledge extraction task, producing a structured summary;
- [ ] At least one designed role-play instruction, with its actual effect on output style verified;
- [ ] A directly reusable "Five Universal Prompt Templates" document.

## Instructor Tips

- This is the only chapter in the entire course that doesn't depend on any software installation, making it suitable as content for a trial/demo lesson to lower the entry barrier for new learners;
- Emphasize that "structured expression" is a skill that can be deliberately practiced, not a talent — use plenty of "before rewrite vs. after rewrite" comparison examples so learners can directly feel the difference;
- The five templates produced in this chapter will be directly reused in Chapter 7, Lesson 7.2, "Building a Personal Prompt Template Library," as the starting material for that lesson's asset-organizing work. Instructors can preview this continuity in advance.
