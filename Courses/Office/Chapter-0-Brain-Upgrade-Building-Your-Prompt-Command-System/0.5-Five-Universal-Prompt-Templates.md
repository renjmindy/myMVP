### I. This Lesson's Positioning: From Methodology to a Reusable Asset

- 0.1 taught the structured framework, 0.2 taught the collaboration mode, 0.3 taught knowledge extraction, 0.4 taught role design — these are all "methods";
- This lesson turns these methods into five "ready-to-use" templates that cover the five most frequent daily task types, so you don't have to think from scratch every time about how to organize your Prompt.

### II. The Five Universal Templates

**Template 1: Task Execution Template (corresponds to 0.1)**

```
Goal: [What this task needs to accomplish]
Context: [Background information that's needed]
Format: [The expected form of the output]
Constraints: [Boundaries that can't be crossed]
```
Applicable to: any specific task with a certain level of complexity.

**Template 2: Iterative Feedback Template (corresponds to 0.2)**

```
[The part to keep] should remain unchanged;
[The part that needs revision] should be changed to [specific requirement];
[List any additional revision items here]
```
Applicable to: making precise, local revisions to an existing Artifact/output.

**Template 3: Knowledge Extraction Template (corresponds to 0.3)**

```
Purpose: I'm extracting this content in order to [follow-up use]
Dimensions: Please organize by [classification dimension]
Format: [output structure]
Verification: Please confirm whether any [key information type] has been missed
```
Applicable to: extracting information from long files, long conversations, meeting records, etc.

**Template 4: Role-Based Review Template (corresponds to 0.4)**

```
Who: You are a [professional identity]
Perspective: Always focus on [core focus]
Tone: [tone/style]
Scope: Responsible only for [specific scope]; no need to evaluate [excluded scope]
```
Applicable to: tasks that require review/evaluation from a specific professional perspective.

**Template 5: Multi-Option Comparison Template (a combined application)**

```
For [task], please provide [N] different directional options.
For each option, explain: the core approach, the advantages, and the
potential risks.
Finally, give your recommendation with reasoning (but don't make the final
decision for me).
```
Applicable to: scenarios that require deciding among multiple directions, avoiding a situation where AI gives a single answer with no room for comparison.

### III. Hands-on: Organizing Your Own Template Document

1. Review your homework from 0.1–0.4 item by item, and identify the specific phrasing that actually tested well for you;
2. Compare against the five templates above, and make personalized adjustments based on your own natural language habits (no need to copy them word for word);
3. Save it as `docs/Five-Universal-Prompt-Templates.md`, as an asset you can open and copy from at any time.

### IV. The Mindset for Using Templates

- Templates aren't meant to have you mechanically copy the format — they're a reminder to ask "for this task, is there an element I've forgotten to think through?";
- Once you're skilled at this, you'll often naturally weave these elements into a single sentence, without literally writing them out line by line — the goal is to internalize this as a thinking habit, not to depend on the template itself.

## Frequently Asked Questions

**Q: Are these five templates enough? What if I run into a task none of them fit?**
A: The five templates cover the most frequent task types. In actual work, you will definitely encounter situations that require adaptation or combining templates — that's normal. The templates provide a "starting point for thinking," not a one-size-fits-all formula that covers every scenario.

**Q: If I learn a new, effective way of phrasing things later, should I update this document?**
A: Yes — it's recommended to build the habit of adding to it as you go, letting this document keep growing. This habit itself is also an early rehearsal of the "Personal AI Resource Library" methodology from Chapter 7.
