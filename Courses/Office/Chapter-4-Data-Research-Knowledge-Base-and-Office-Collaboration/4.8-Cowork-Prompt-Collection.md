# 4.8 | Cowork Prompt Collection

- Complete this lesson's deliverables: a personal Cowork prompt collection document and an AI collaboration SOP checklist.

## Course Outline

### I. Why Compile a "Prompt Collection"

- Revisit the custom-command approach learned in 1.6 — save reusable prompts to reduce the cost of reorganizing your wording each time;
- Chapter 4's lessons 4.1–4.7 have already produced a large number of battle-tested prompts (file organization, spreadsheet cleaning, competitive analysis, external tool syncing). This lesson systematizes and templates them, turning them into directly reusable assets.

### II. The Method of Prompt Templating

Transform "a prompt that worked well once" into "a reusable template." The core is identifying which parts are **fixed structure**, and which parts are **parameters that change each time**.

**Example: Templating the File-Organization Prompt Used in 4.4**

Original prompt (one-off):
```
Please help me organize this batch of files, categorizing according to the following rules:
1. First split into: documents, spreadsheets, images, other, based on file type
2. Further subdivide the documents category into subfolders by topic
3. Rename all files uniformly to a "date-brief description" format
```

Templated version (reusable, with `[]` marking replaceable parameters):
```
Please help me organize the files in [target folder], categorizing according to the following rules:
1. First categorize by [categorization dimension]
2. [sub-categorization rule, omit if not applicable]
3. File naming rule: [naming format]
Please give me a categorization plan first, and I will confirm it before you execute
```

### III. Chapter Prompt Collection Summary (Reference for Learners to Organize)

### IV. Hands-On: Compile Your Personal Prompt Collection

1. Review the prompts you actually used and found effective during your hands-on work in 4.1–4.7;
2. Organize them into the four scenario categories above, templating each one (marking the replaceable parameters);
3. Save it as `docs/Cowork-Prompt-Collection.md`;
4. Optional advanced step: pick 2–3 of your most frequently used templates and, using the method from 1.6, turn them into formal custom commands, achieving "one-click invocation."

### V. AI Collaboration SOP Checklist: More Than Just Prompts — a Process Standard

- The prompt collection records "how to ask"; the SOP checklist records "how the entire collaboration process should proceed" — including what needs to be prepared before the task starts, what you need to check after the AI finishes, and in what situations human intervention is required. It is a more complete collaboration standard than any single prompt;
- Give learners a directly applicable SOP checklist template:

```markdown
## [Task Type] AI Collaboration SOP

**Preparation before starting**:
- [ ] ... data/files that need to be prepared

**Execution steps**:
1. ...

**Checklist** (items you must manually verify after the AI is done):
- [ ] ...

**Exception handling**:
- If ..., then ...
```

- Hands-on: using the "file organization" or "spreadsheet cleaning" task already practiced in this chapter as an example, organize the scattered operational steps into a formal SOP checklist, and save it as `docs/AI-Collaboration-SOP-Checklist.md`. This checklist serves a different purpose than the prompt collection — the prompt collection is a "material library," while the SOP checklist is a "process standard." Using the two together makes collaboration both efficient and reliable.

## Frequently Asked Questions

**Q: Does the prompt collection need to be updated frequently?**
A: It's recommended to build the habit — every time you use Cowork to complete a new type of task or figure out a phrasing that works well, add it to the collection right away, letting it become a continuously growing personal asset rather than a one-time assignment.

**Q: What's the relationship between the prompt collection and the "template library" in Chapter 7?**
A: This lesson is the starting point of accumulation; Chapter 7 will explain a more systematic approach to building a template library (categorization system, version management, team sharing, etc.). The content organized in this lesson will directly serve as the base material for the hands-on work in Chapter 7.

**Q: Should the SOP checklist and the prompt collection be stored separately?**
A: It's recommended to keep them as two separate documents (`docs/Cowork-Prompt-Collection.md` and `docs/AI-Collaboration-SOP-Checklist.md`) — the former contains concrete, copy-paste-ready phrasing, while the latter is a process-level checklist. Mixing them together tends to blur the purpose of each.
