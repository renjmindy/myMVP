## 開始之前：先打開一個免費開關（很重要，30 秒）

claude.ai 的「Skills（技能）」功能，**需要先開啟「Code execution」才會運作**——這個開關**免費版本來就免費可以開**，不是付費功能。

**做一次就好：**
1. claude.ai → 左下角你的頭像 → **設定（Settings）**
2. 進 **Capabilities（功能）**
3. 把 **「Code execution and file creation（程式碼執行與檔案建立）」打開**

> ⚠️ **這步沒開，等一下技能上傳了也不會有反應**——這是「裝了卻用不動」最常見的原因。先開好再往下走。

---

## 第一步：裝技能（下載 → 上傳 → 開啟，三步）

> 📱 **⚠️ 上傳這一步請用「電腦」做**：手機、iPad 的 App 沒有上傳技能的入口，**一定要先在電腦（claude.ai 網頁版）把這 7 個 zip 上傳、裝好一次**。裝好之後，因為免費版的技能存在你的雲端帳號裡，手機、iPad 登入同一個帳號就會自動同步、可以直接用了。

1. 下載 `hugo.zip`（先不用解壓縮，保持 zip）
2. claude.ai → 左下角你的頭像 → **設定（Settings）** → **Capabilities** → 滑到最下面點「Skills have moved to Customize」→ 進到 Skills 頁後，點右上角的「**＋**」→「**Create skill**」→「**Upload a skill**」
3. 選 `hugo.zip` 上傳 → 列表出現「hello-hugo」→ **把開關打開**

其他六個一樣：下載 → 上傳 → 開啟。

> ### ⚠️ 上傳「三不」——這是免費版最多人卡的地方
> 1. **不要傳「說明檔」（`.md`）**——`SKILL.md`、`unit-0.md` 這些都是給你看的說明，不是技能。要傳的**只有表格裡那 7 個 `.zip`**。
>    - 🔴 傳成 `.md` 會跳：`SKILL.md must start with YAML frontmatter (---)`——傳錯檔了，改傳 zip。
> 2. **不要走「Upload plugin（上傳外掛）」那個入口**——要走 **設定 → Customize → Skills → 右上角「＋」→「Create skill」→「Upload a skill」**。
> 3. **不要把 zip 解壓再重壓**——直接傳表格裡那 7 個**原始 zip**。
>
> 💡 一句話記法：**要傳的是「7 個 zip」，一個一個傳，不解壓、不重壓、走「Create skill」。**

## 第二步：跟 Hugo 打招呼，讓他訪談你

✏️ 開新對話，輸入：

```
/hello-hugo 你好
```

Hugo 會自我介紹，然後**反過來訪談你**——問你的稱呼、做什麼、目前最想解決的痛點。你用講的回就好，他幫你把資料記在這個對話裡。

> 💡 **免費版重點：你的資料存在「對話」裡，不是檔案。** 所以盡量**同一週的工作待在同一個對話**完成，Hugo 才記得你。開新對話＝重新自我介紹（claude.ai 設定裡若有「Memory／個人化記憶」可以打開，跨對話也記得大方向）。
>
> ⚠️ **真的要開新對話前**：先請 Hugo「幫我把資料摘要列出來」，複製貼到新對話開頭，他就能無縫接上、不用重新訪談你。

## 第三步：一句話派工，team 動起來

✏️ 你只跟 Hugo 說話，他會自動找對的人：

```
/hello-hugo 幫我整理今天的信箱
```

Hugo 判斷這是信箱的事 → 交給 Robin → 當場整理出日報。

## 第四步：手動使用（免費版的最後一哩）

免費版沒有自動串接，但只差一個動作：**複製 → 貼到你要用的地方 → 完成**。

- Robin 整理好日報 → 你複製貼到 Notion／記事本
- Kai 做好落地頁 → 你存成 `.html`，放上免費拖拉托管（如 Netlify Drop）或自己的平台
- Mia 寫好貼文 → 你複製貼到 IG/Threads 發布
- Ray 寫好腳本 → 你用 CapCut／剪映拍剪
- Theo 拆解好競品 → 你自己保存記錄，下次貼回來比對
- Ada 擬好回覆 → 你複製貼回客戶留言，或貼進 LINE 官方帳號的自動回應設定

> 對剛起步的你，這樣反而最穩——用出前再用自己的眼睛確認一次。

## 免費版 vs 付費版差在哪？

**免費版該有的「腦力」一個都不少**——七位夥伴都能裝能用，判斷、文案、規劃都幫你做好。

差別只有一個詞：**自動化**。
- 免費版：Robin 整理好日報，你複製貼上存；Kai 做好頁面，你自己找地方放上線
- 付費版（Claude Code）：接上工具後，連讀信、部署、發文、回客服都幫你排好

先用免費版把流程跑順、團隊用熟。等哪天「手動貼上有點花時間」，再升級 Claude Code 也不遲——完整版團隊在 `../skills/`，跟著 `../course/` 課綱走。

## 卡關怎麼辦

看到問題，**先問 Claude**：把錯誤貼給它，問「這個錯誤為什麼？幫我修正」。

兩個最常見：
- 技能裝了沒反應 → **先確認「Code execution」開關有開**（設定 → Capabilities）；再確認該技能本身的開關也打開
- 跳出已達使用上限 → 等額度重置
