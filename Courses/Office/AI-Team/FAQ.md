# 常見問題 Q&A

> 卡關時，先翻這裡。大多數狀況這份都能幫你解掉。

---

## 🧰 團隊與工具

### Q：我完全不會寫程式，用得起來嗎？

可以。整套團隊的設計就是**不用懂程式**——你只要會「打字跟 Hugo 說話」「複製貼上」就行。遇到看不懂的指令，直接把它貼給你的 Claude，問「這是什麼、我該怎麼做」，它會用白話帶你。

### Q：一定要付費的 Claude Pro 嗎？免費版能做什麼？

不一定。**免費版（claude.ai 網頁版）該有的「腦」一個都不少**——七位成員的問答、規劃、寫作、判斷能力完整，差別只在「手腳」（自動讀信、自動部署、自動發文這些自動化）。

- **先用免費版**把流程跑順、把內容做出來，手動複製貼上使用，完全沒問題。
- 需要自動化（排程、串接工具）再升級 **Claude Pro（約 US$20／月）**。

免費版用法見 [free-version/README.md](free-version/README.md)。

### Q：Mac 和 Windows 都能用嗎？

都可以。Claude Code 已原生支援 Windows，**不需要 WSL**。安裝指令見 [INSTALL.md](INSTALL.md)。

### Q：可以用手機或 iPad 安裝、使用嗎？

**安裝一定要用電腦（Mac／Windows），手機和 iPad 沒辦法安裝。**

之後想在 iPad／手機上「使用」是可以的，但有兩個前提：
1. 只能用**免費版**（claude.ai 網頁版上傳技能的那種，技能會同步到你的雲端帳號）
2. **一定要先用電腦完整安裝過一次**，手機／iPad 登入同一個帳號才會同步、才用得到

一句話：**先在電腦裝好，手機才用得到。**（Claude Code 的本機自動化功能仍是電腦專屬。）

### Q：可以同時管理兩個品牌/事業嗎？

**建議一次專心一個。** 團隊設計上是「單一個人資料」——七位成員都固定讀同一份 `~/.claude/skills/_base/`，沒有內建「切換」功能。

真的要同時顧兩個，只能土法分開：
- **免費版**：一個品牌用一個對話（或用 claude.ai 的「Projects」各開一個）
- **付費版**：`_base/` 是本機檔案，只能手動把整個資料夾換掉（另存改名再換回來），容易搞混，不建議常態這樣用

### Q：換一台電腦，資料會跟著嗎？

- **免費版**：技能和資料跟著你的 claude.ai 帳號走，換裝置登入同一帳號就在
- **付費版**：資料是本機檔案，**不會自動跟著走**。換電腦要重裝一次團隊，再把舊電腦的 `~/.claude/skills/_base/` 複製過去

## 🛠️ 安裝與更新

### Q：桌面 App 裡的 Chat、Cowork、Code 有什麼差？安裝要用哪個？

- **Claude Code**＝碰得到你電腦檔案、能跑指令。**安裝團隊、複製技能，一定用這個。**
- **Cowork**＝雲端工作區，碰不到你電腦的檔案。**裝好之後**日常叫團隊做事用它反而最順。
- **Chat**＝一般聊天。

一句話：**「安裝」用 Code，「之後叫團隊做事」用 Cowork。** 在 Chat／Cowork 貼安裝指令會跳「沙盒跟你的電腦是分開的」——不是壞掉，改用 Claude Code 就對了。

> ⚠️ 三個分頁的內容互不相通：在 Code 裝好的團隊，Chat 那邊叫不出來是正常的，不用重裝。

### Q：裝完輸入 `/hello-hugo` 卻說「找不到指令」？

照順序檢查：
1. **沒複製到位**：確認 `~/.claude/skills/hello-hugo/` 裡真的有檔案。沒有就回 [INSTALL.md](INSTALL.md) 重做一次。
2. **沒「完全」重開**：安裝後一定要**完全關閉 Claude Code 再重新打開**，不是按紅色叉叉縮小。
3. **（免費版專屬）沒開 Code execution 開關**：見 [free-version/README.md](free-version/README.md)。

### Q：怎麼更新團隊到最新版？

如果你的團隊技能是從共用資料夾複製安裝的，跟 Hugo 說一句「**更新團隊**」，他會帶你重新同步 `skills/*`，**你的 `_base/` 個人資料不會被動到**。

### Q：不想要了，怎麼移除？

見 [INSTALL.md 的「🗑️ 一鍵刪除碼」](INSTALL.md#️-不想要了一鍵刪除碼)。

## 🆘 卡關自救

### Q：如果遇到問題怎麼辦？

**第一時間，先把問題丟給你自己的 Claude 去解決。** 把錯誤訊息、你在做什麼、卡在哪，原原本本貼給它，請它幫你診斷。多數問題它當下就能幫你解掉。

### Q：Claude 突然當機、卡住、轉圈圈不回應，怎麼自救？

1. **換一個模型**：`/model` 切換成另一個再試——最常見的解法
2. **開一個新對話重試**：對話太長容易卡，開新對話往往就順了
3. **完全關閉 Claude Code（或重新整理網頁）再打開**
4. **內容太長就分段給**：一次貼太多字會超出負荷
5. **可能是網路或用量上限**：檢查網路；免費版額度用完就等重置或升級

## ⚙️ 自動化與平台串接

### Q：Google 日曆／LINE Bot 串接看起來好難，一定要弄嗎？

不一定，這些都是**進階、可以直接跳過**的部分。沒串接也不影響——對應成員一樣會把該做的事列成清單給你，你自己手動處理就好。等哪天真的覺得手動有點煩，再回去照 `ADVANCED-*.md` 串也不遲。

### Q：Hugo 不是會自動追進度、提醒我嗎？為什麼都要我先開口？

對，預設是「**你開口，他才動**」——你問「進度總覽」他就盤點給你。真正「每天早上自動跳出來提醒」那種，要額外接排程工具（見 `course/unit-9-automation.md`），不是裝好就會自己跑。

### Q：為什麼裝好了還不能自動發文、自動部署、自動回覆？

團隊的「**腦**」（判斷、文案、規劃）裝好就完整能用；但「**手腳**」（自動發文、自動部署、自動回覆）需要你自己去接對應工具（Vercel、Buffer、LINE API…），部分還要花錢或申請帳號。先用「腦」把內容做出來、手動用，流程跑順了再接自動化也不遲。

### Q：（免費版）怎麼讓 Claude 跨對話記得我的資料？

免費版的資料是記在「**這個對話**」裡的，所以同一週的工作盡量待在同一個對話完成最穩。真的要開新對話前，先請 Hugo「**幫我把資料摘要列出來**」，複製貼到新對話開頭，他就能無縫接上。
