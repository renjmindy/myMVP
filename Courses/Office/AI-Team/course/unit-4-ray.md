- **4-1　主題 → 短影音腳本**：黃金 3 秒開場 + 逐段腳本 + 分鏡建議
- **4-2　配音 + 字幕 + 剪輯**：AI 配音、自動聽打字幕、轉尺寸、加配樂
- **4-3　上架**：整理好標題/描述/標籤，接好 API 可直接發布

> 想看 Ray 完整能耐？裝好後直接問他「**你會做什麼**」。

✏️ 給他一個主題（有沒有現成素材都可以）：


他應該先確認平台、長度、素材狀況，然後給你一份含黃金 3 秒開場的完整腳本。這樣就算過關。

---

## Ray 的 3 個技能點（跟著做，一項一驗收）

### 4-1　主題 → 短影音腳本

照 ✅ 驗收任務那句開始。他會依平台（Reels/Shorts）、長度、素材狀況給出固定格式腳本：每段畫面 + 口白，結尾一定有明確 CTA。

> ✅ **驗收**：拿到的腳本開場 3 秒是「停止滑走」的鉤子（疑問句、反差、數字清單），不是平鋪直敘的介紹。

### 4-2　配音 + 字幕 + 剪輯

✏️ 腳本確認後（或你已經有拍好的照片/影片素材）：

```
/ray-video 幫我把這些素材配音、上字幕、剪成 Reels
```

他會：AI 配音 → 自動聽打字幕（校對錯字）→ 燒字幕（安全區位置、字級規範）→ 轉 9:16 尺寸 → 需要的話加配樂。

> ✅ **驗收**：拿到一支 9:16 的完整影片檔，字幕位置在畫面中段（不貼頂也不貼底），配音聽得清楚。
> 💡 **實測範例**：這個團隊真的用這套流程做過「2026 暑期游水趣」系列 Reels——從一批活動照片，出腳本、配 zh-TW 神經網路語音、燒字幕、配上原創合成配樂，一路做到成品 mp4。整個流程可以完全不需要真人出鏡拍攝，用現成照片＋Ken Burns 運鏡也能剪出完整短影音。

> ⚠️ **配樂老實話**：Ray 不會去網路上抓版權不明的歌曲。沒有授權音樂素材時，他可以用程式合成一段原創旋律當「佔位配樂」（安全但陽春），正式要發布、想要更好聽的配樂，建議還是用 IG／CapCut 內建的免費音樂庫。

### 4-3　上架

✏️ 影片做好後：

```
/ray-video 幫我準備上架的標題、描述、標籤
```

API 已接會直接幫你發布；沒接的話，他會把標題／描述／標籤準備好，你手動上傳。

> ✅ **驗收**：拿到一組可以直接貼上去的標題＋描述＋標籤。
