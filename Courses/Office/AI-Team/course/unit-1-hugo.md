# Unit 1｜聘請 Hugo，你的團隊總管

> 這個單元完成後，你有了整個團隊的指揮中心——不確定該找誰時，先找他就對了。

---

## 你會得到什麼

一個叫做 **Hugo** ☕ 的 AI 團隊總管，有 **4 個技能點**，這個單元會帶你一個一個用過、每個都當場驗收：

- **1-1　任務判斷與派工**：你說出困擾，他判斷該叫誰、給出完整交辦 brief、切換角色
- **1-2　進度總覽**：一句話請他彙整全隊最近做了什麼、工具接了沒、下一步建議
- **1-3　跨角色協作建議**：不確定兩個任務該怎麼串起來時，查他的花名冊給組合建議
- **1-4　團隊更新**：整個團隊的技能檔要更新時，他負責重新同步（保留你的 `_base/` 個人資料）

> 想看 Hugo 完整能耐？裝好後直接問他「**你會做什麼**」。

## Step 1：跟 Hugo 打招呼（如果 Unit 0 還沒做）

✏️ 輸入：

```
/hello-hugo 你好
```

Hugo 會：
- 讀取 `_base/` 的個人資料
- 介紹自己跟六位夥伴
- 回報 `business-profile.md` 的完整度
- 問你今天想解決哪個痛點

## ✅ 驗收任務

✏️ 給 Hugo 一個具體的困擾：

```
/hello-hugo 我每天早上都要花很久整理信箱，有什麼辦法？
```

他應該：判斷這是 Robin 的工作 → 在對話裡當著你的面給 Robin 一份交辦 brief → 切換成 Robin 的身份接手（訊息開頭會出現 📥 emoji）。
這樣就算過關。

---

## Hugo 的 4 個技能點（跟著做，一項一驗收）

### 1-1　任務判斷與派工

✏️ 不管什麼困擾，直接跟 Hugo 說：

```
/hello-hugo 我要賣一個線上課程，需要一個落地頁
```

他會給出交辦 brief（目標、背景、要產出什麼、工具狀態），然後切換成 Kai 接手。

> ✅ **驗收**：Hugo 有講出完整 brief，而且切換角色後，接手的成員第一句話有「接住」剛才的脈絡（不是重新問你一次要做什麼）。

### 1-2　進度總覽

✏️ 想知道整個團隊做到哪了：

```
/hello-hugo 進度總覽
```

他會彙整 `_base/task-log.md`、`tool-inventory.md`、`business-profile.md`，給你：各成員最近動態、工具串接狀態、1-3 個建議下一步。

> ✅ **驗收**：你拿到一份固定格式的總覽，看得出誰做了什麼、什麼工具還沒接、下一步是什麼。

### 1-3　跨角色協作建議

✏️ 兩個任務想串起來時：

```
/hello-hugo 落地頁上線後，還可以請哪個夥伴幫忙推廣？
```

他會查 `references/team-roster.md` 的跨角色協作組合，例如「Kai → Mia：落地頁上線後社群同步宣傳」。

> ✅ **驗收**：你拿到具體的協作建議，而不是「都可以」這種模糊話。

### 1-4　團隊更新

✏️ 如果你的團隊技能檔是從共用資料夾或 repo 複製安裝的：

```
/hello-hugo 更新團隊
```

他會重新同步 `skills/*`，**跳過 `_base/`**，不會動到你的個人資料。

> ✅ **驗收**：更新完成後，`_base/business-profile.md` 裡你填過的內容還在。
