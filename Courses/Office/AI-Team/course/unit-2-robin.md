# Unit 2｜聘請 Robin，你的收件匣管家

> 這個單元完成後，你不用再自己掃過整個信箱找重點。

---

## 你會得到什麼

一個叫做 **Robin** 📥 的 AI 收件匣管家，有 **3 個技能點**，這個單元會帶你一個一個用過、每個都當場驗收：

- **2-1　每日信箱摘要 → 日報**：一批信整理成「總覽 → 分類 → 建議」的固定格式日報
- **2-2　Gmail / Notion / LINE 串接**：接好之後日報可以自動推送、累積可搜尋
- **2-3　時效性提醒抓取**：從信件內容抓出帳單到期、活動截止這類 deadline

> 想看 Robin 完整能耐？裝好後直接問他「**你會做什麼**」。

---

## Robin 已經裝好了 ✅

Unit 0 的「一次裝好整個團隊」已經把 Robin 一起裝好了，這個單元直接開始用他。

---

## Step 1：跟 Robin 打招呼

✏️ 輸入：

```
/robin-inbox 你好
```

他會用白話介紹自己能做什麼、怎麼叫他做事。

---

## ✅ 驗收任務

✏️ 給他一批信（貼內容、轉寄、或截圖都行）：

```
/robin-inbox 幫我整理今天的信箱重點：[貼上幾封信的內容]
```

他應該給你一份固定格式的日報：總覽（幾封待回/留意/通知）→ 分類清單 → 今天最該優先處理的建議。這樣就算過關。

---

## Robin 的 3 個技能點（跟著做，一項一驗收）

### 2-1　每日信箱摘要 → 日報

✏️ 確認範圍後直接整理：

```
/robin-inbox 幫我整理最近 24 小時的信箱
```

Gmail 已接會自動拉信；沒接的話把要處理的信轉寄或貼給他，他一樣整理。

> ✅ **驗收**：你拿到「🔴 要今天回 / 🟡 留意 / ⚪ 純通知」分類清楚的日報，並標出今天最優先的一件事。

### 2-2　Gmail / Notion / LINE 串接

✏️ 想要日報自動推送、累積可搜尋：

```
/robin-inbox 幫我設定
```

他會依序帶你接 Gmail（讀信）、Notion（存日報）、LINE（選配，即時推播），每步都會驗證。

> ✅ **驗收**：至少一個工具接好後，狀態能在 `_base/tool-inventory.md` 看到 ✅。
> ⚠️ **老實話**：接好工具只代表「Robin 有能力自動做」，要「每天早上 8 點自己跑」還需要 Cron 或 Vercel Cron 排程觸發——見 Unit 9。

### 2-3　時效性提醒抓取

✏️ 整理日報時，他會順手抓時效性資訊，你也可以單獨問：

```
/robin-inbox 這批信裡有沒有帳單或截止日要注意的？
```

> ✅ **驗收**：他列出有明確日期的事項，並問你要不要加進 Google 日曆提醒。

---

## 小提示

> Robin 抓重點很狠——一封信只留「跟你有關的那句話」，不會整封信照抄。不確定的分類會誠實標「建議你看一眼」，不會硬猜。
>
> 想直接找他、不透過 Hugo，可以打 `/robin-inbox`。
