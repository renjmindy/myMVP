# Unit 5｜聘請 Mia，你的社群排程機器人

> 這個單元完成後，你再也不用每天絞盡腦汁想貼文。

---

## 你會得到什麼

一個叫做 **Mia** 📱 的 AI 社群排程機器人，有 **2 個技能點**，這個單元會帶你一個一個用過、每個都當場驗收：

- **5-1　一週社群內容批次產出**：7 天文案 + 配圖提示詞 + 發布時段建議
- **5-2　Buffer / 排程 API 串接**：接好之後可以定時自動發布，不用手動貼

> 想看 Mia 完整能耐？裝好後直接問她「**你會做什麼**」。

---

## Mia 已經裝好了 ✅

Unit 0 的「一次裝好整個團隊」已經把 Mia 一起裝好了，這個單元直接開始用她。

---

## Step 1：跟 Mia 打招呼

✏️ 輸入：

```
/mia-social 你好
```

---

## ✅ 驗收任務

✏️ 給她一個主題方向：

```
/mia-social 排這週的貼文，主題是 [你的產品或活動]
```

她應該先問內容類型（促銷／品牌／混合）跟平台，接著給一份排程草案（日期/平台/形式/主題），確認後才逐篇展開。這樣就算過關。

---

## Mia 的 2 個技能點（跟著做、一項一驗收）

### 5-1　一週社群內容批次產出

照 ✅ 驗收任務那句開始。確認排程草案後，她會一篇一篇產出：完整文案（含 hashtag）+ 配圖 Prompt（可直接貼進生圖工具）+ 發布時段建議；適合輪播的主題會標成輪播規劃。

> ✅ **驗收**：至少拿到一篇完整貼文，含文案、配圖 Prompt、發布時段三樣都有。

### 5-2　Buffer / 排程 API 串接

✏️ 想要排好之後自動發布：

```
/mia-social 幫我設定排程工具
```

她會帶你選 Buffer（最簡單）或 IG/Threads 官方 API（功能完整但設定較多），逐步接好並驗證。

> ✅ **驗收**：至少接好一個排程管道，狀態能在 `_base/tool-inventory.md` 看到 ✅。
> ⚠️ **老實話**：內容生成隨時能做，但「定時自動發布」才需要排程工具；IG 的「原生未來排程」目前官方 API 不支援，要嘛時間到觸發、要嘛用 Meta 內建工具排。

---

## 小提示

> Mia 節奏快、句子短、不廢話，而且懂平台脾氣——同一個主題發 IG 跟發 Threads 會是不同版本，不會複製貼上硬套兩邊。
>
> 想直接找她、不透過 Hugo，可以打 `/mia-social`。
