## 你會得到什麼

一個叫做 **Kai** 🛠 的 AI 落地頁工程師，有 **3 個技能點**，這個單元會帶你一個一個用過、每個都當場驗收：

- **3-1　一句話 → 完整落地頁**：文案、配色、版面一次到位，一塊一塊帶著確認
- **3-2　配色與 SEO 內建**：Meta 標籤、Open Graph 全部內建在頁面裡，不用另外處理
- **3-3　一鍵 Vercel 部署**：頁面確認後直接上線，拿到可分享網址

> 想看 Kai 完整能耐？裝好後直接問他「**你會做什麼**」。

## ✅ 驗收任務

✏️ 給他一個真實的產品/服務：

```
/kai-pages 我要賣 [你的產品或服務]，幫我做一個落地頁
```

他應該先問清楚頁面目的（收名單／直接賣／報名活動），接著給你「整頁藍圖」，然後一塊一塊（Hero → 痛點 → 解方 → …）做成有質感的 HTML，每塊都會先給你看、問要不要調。這樣就算過關。

---

## Kai 的 3 個技能點（跟著做，一項一驗收）

### 3-1　一句話 → 完整落地頁

✏️ 照 ✅ 驗收任務那句就可以開始。做法一律「**一塊一塊帶著做，不要一次吐整頁**」——每塊：寫真實文案 → 做成有設計感的 HTML → 給你看 + 問要不要調。

> ✅ **驗收**：全部區塊做完後，你拿到一個雙擊就能在瀏覽器打開、手機版排版正常、CTA 明顯的完整單檔 HTML。

### 3-2　配色與 SEO 內建

✏️ 沒有品牌色時：

```
/kai-pages 幫我出配色方向
```

他會給 3 個方向（質感暗調／明亮生活／極簡文字）讓你選，選完才出稿；SEO（Meta 標題、Description、Open Graph）全部內建，不用另外處理。

> ✅ **驗收**：頁面 `<head>` 裡看得到含主張的 `<title>`、`<meta description>`、`og:title/og:description`。

### 3-3　一鍵 Vercel 部署

✏️ 頁面確認滿意後：

```
/kai-pages 幫我把這頁部署上線
```

第一次會先確認 Vercel 帳號（免費註冊即可），接著用 CLI 或拖拉方式部署，拿到正式網址。

> ✅ **驗收**：你拿到一個 `https://....vercel.app` 或自訂網域的網址，打開能正常瀏覽。
> ⚠️ **老實話**：一鍵部署指的是「頁面做好後幫你跑完部署指令」，不是「以後改需求也自動更新」——每次調整內容都要再跑一次部署。
