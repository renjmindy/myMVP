# Unit 9｜進階自動化：讓團隊自己定時跑（選用）

> ⚠️ 這個單元是**選用**，不是必做。前面八個單元裝完，團隊已經完整可用——只是每個能力都要「你開口」才會動。這個單元教你怎麼讓它們**不用開口、自己在固定時間跑**。

---

## 為什麼需要這個單元

你會發現每位成員的 SKILL.md 裡都誠實寫了同一句話：

> 「我不會自己在指定時間醒過來跑——要做到『不用開口，自動出現』，需要排程工具在背後觸發我。」

這不是團隊偷懶，是老實話：Claude Code 本身是「你打開、它才回應」的工具，沒有排程器幫忙，沒有任何 AI 助理能無中生有地在你沒開對話的時候自己動起來。

這個單元教你接上這一層。

---

## 你會得到什麼

- 了解兩種排程方案的差異，選出適合你的
- 一支範例腳本，示範怎麼讓 Robin 每天早上自動推送信箱日報
- 知道怎麼把同一套方法套用到 Theo（每日監控）、Mia（定時發文）等其他成員

---

## 方案比較

| 方案 | 說明 | 適合情境 | 缺點 |
|---|---|---|---|
| **本機 Cron / 工作排程器** | 電腦要開著，用 Mac/Linux 的 `crontab` 或 Windows 工作排程器，在指定時間執行一支呼叫 Claude Code 的腳本 | 電腦習慣整天開著、想先試試看 | 電腦關機/睡眠就不會跑 |
| **雲端方案（Vercel Cron）** | 把邏輯包成腳本部署到 Vercel，用 Vercel 內建的 Cron 功能定時觸發 | 想要電腦關著也會跑的真全自動 | 需要先請 Kai 協助部署環境，設定步驟較多 |

> 💡 想快速體驗效果，建議先用本機 Cron 試一輪；確定這個自動化值得長期投資，再請 Kai 協助搬到 Vercel Cron。

---

## Step 1（本機方案）：Mac / Linux 用 Cron

✏️ 打開終端機（不是 Claude Code，是系統的終端機），輸入：

```bash
crontab -e
```

加入一行（範例：每天早上 8 點觸發 Robin 整理信箱）：

```
0 8 * * * cd ~/path/to/your/project && claude -p "/robin-inbox 幫我整理今天的信箱，推送到 Notion 和 LINE" >> ~/robin-cron.log 2>&1
```

儲存後，Cron 會在每天 8:00 自動執行這行、把 Robin 的回應記錄進 `~/robin-cron.log`。

> ⚠️ `claude -p` 是非互動模式，需要 Claude Code CLI 已經登入過、且該任務不會卡在需要人工「允許」的步驟——建議先手動跑過一次同樣的指令確認流程順暢，再排進 Cron。

---

## Step 2（本機方案）：Windows 用工作排程器

1. 開啟「工作排程器」（Task Scheduler）
2. 建立基本工作 → 設定觸發時間（例如每天 8:00）
3. 動作選「啟動程式」，程式路徑填你的 `claude` 執行檔位置，引數填：
   ```
   -p "/robin-inbox 幫我整理今天的信箱，推送到 Notion 和 LINE"
   ```
4. 設定「起始位置」為你的專案資料夾

---

## Step 3（雲端方案）：Vercel Cron

這個方案需要把觸發邏輯包裝成一個可以被 HTTP 請求呼叫的端點，並在 Vercel 專案裡設定 `vercel.json` 的 `crons` 區塊。步驟較多、需要一點部署經驗：

> 這步建議直接請 Kai 協助——他熟悉 Vercel 部署流程，可以幫你把整套自動化包裝成雲端排程。跟他說：

```
/kai-pages 我想把 Robin 的每日信箱摘要排程搬到 Vercel Cron，電腦關著也要能跑，幫我設計架構
```

## 套用到其他成員

同樣的排程方法可以套用到：

- **Theo**：`/theo-watch 競品有什麼動靜？` 排每天早上 7 點
- **Mia**：排程發文本身建議先用 Buffer 內建排程（不需要 Cron，Buffer 自己會按時間發），只有走「官方 API 直發」才需要 Cron 觸發
- **Ada**：LINE Webhook / Email 收信本身就是雲端觸發，不太需要額外排程

---

## 小提示

> 排程是「投資報酬率」的問題——不是每件事都值得自動化。先手動用順某個能力，確定它真的每天在幫你省時間，再花時間把它排程化。
>
> 團隊裡的每一位成員都不會假裝「裝完就全自動」，遇到需要排程的地方都會老實告訴你——這個單元就是把那句「老實話」變成實際能跑的設定。
