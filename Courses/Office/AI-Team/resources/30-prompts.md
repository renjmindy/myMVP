# 🎁 30 個實戰 Prompt 食譜（複製貼上就能用）

> 這不是「單元重點複習」，而是 30 個**真實情境的組合技食譜**——常常一句話就讓 Hugo 同時調度好幾位夥伴，把跨角色的打法直接打包給你。
> 把 `[方括號]` 換成你的內容，貼進 Claude Code 就會動。挑你這陣子正要做的那件事，從那一條開始。

**怎麼用**

- 整句連 `/hello-hugo` 一起貼，Hugo 會判斷該找誰、給交辦 brief、切換角色執行。
- 想跳過 Hugo、直接找某位成員，把 `/hello-hugo` 換成對應指令（`/robin-inbox`、`/kai-pages`、`/ray-video`、`/mia-social`、`/theo-watch`、`/ada-support`）也通。
- 方括號 `[ ]` 是要你換成自己內容的地方；不確定怎麼填，貼上去後團隊會反問你。

## 🚀 上線與推廣

**1. 新品上線 7 天衝刺**
```
/hello-hugo 我 [日期] 要上 [產品／服務]，幫我排一份 7 天上線衝刺計畫：Kai 出落地頁、Mia 排每天的貼文、Ray 剪一支預告短影音，最後彙整成一張我照著做就行的時間表。
```

**2. 限時優惠活動懶人包**
```
/hello-hugo 我要辦一檔 [優惠內容，例：限時 8 折 3 天] 的活動，幫我一次備好：Kai 出活動頁、Mia 出開賣／提醒／最後一天三波貼文。
```

**3. 倒數催單組合包**
```
/hello-hugo 我的 [產品] 剩 [X] 天就截止，幫我做一套倒數催單：Mia 出多平台倒數貼文、Kai 在落地頁加上倒數提醒文案。
```

**4. 線上活動／直播完整宣傳**
```
/hello-hugo 我 [日期] 要辦 [線上活動／直播／講座]，幫我規劃活動前（預熱報名）、活動中（互動）、活動後（回放導購）三階段的內容與貼文。
```

**5. 產品改版重新上架**
```
/hello-hugo 我的 [產品／服務] 改版了，幫我規劃一波「重新上架」宣傳：Kai 更新落地頁講清楚升級了什麼，Mia 給舊客戶和新客戶各一套說法。
```

## 📥 信箱與行政

**6. 每天自動整理信箱重點**
```
/hello-hugo 幫我設定每天早上把信箱重點整理成日報，推到 Notion 和 LINE。
```

**7. 挖出信箱裡的商機**
```
/hello-hugo 請 Robin 幫我掃過這批信，挑出裡面有商業合作或高意願詢問的信，其他先不用管：[貼上信件內容]
```

**8. 出貨/服務時效性總表**
```
/hello-hugo 請 Robin 幫我抓出信箱裡所有有明確截止日的事（帳單、活動、合約），整理成一張時間表。
```

**9. 客訴/緊急信優先處理清單**
```
/hello-hugo 幫我看這批信裡有沒有客訴或緊急狀況，優先列出來，其他的等一下再看：[貼上信件內容]
```

**10. 信箱轉知識庫**
```
/hello-hugo 這批客戶詢問信裡的常見問題，幫我整理成客服知識庫，之後可以自動回覆。
```

## 🎬 內容生產力

**11. 一批照片變一支短影音**
```
/hello-hugo 我有一批 [活動/產品] 照片，沒有錄影，幫我剪成一支 [平台] 短影音，含配音配樂。
```

**12. 一支影片榨成一週社群素材**
```
/hello-hugo 這支影片的重點是 [貼上逐字稿或重點]，幫我切成一週可發的素材：短影音腳本、貼文文案、輪播圖卡內容各幾則。
```

**13. 舊內容翻新再利用**
```
/hello-hugo 這是我以前成效不錯的貼文：[貼上]。幫我分析為什麼會中，再用同一個角度重寫 3 個新版本，發不同平台。
```

**14. 短影音系列企劃**
```
/hello-hugo 幫我規劃一個 [主題] 的短影音系列，一次給我 5 集的主題方向和每集的黃金開場句。
```

**15. 把常見問題變成內容**
```
/hello-hugo 我的客戶最常問這些問題：[列幾個]。幫我把它們變成一系列短影音或貼文，順便消除購買疑慮。
```

## 🤖 客服與知識庫

**21. 建立完整客服知識庫**
```
/hello-hugo 把這份產品說明文件建成客服知識庫：[貼上或上傳文件]
```

**22. 異議處理腳本（太貴／再想想）**
```
/hello-hugo 客戶常因為「太貴／再想想」不買，幫我各寫一段不硬銷、站在他立場的回應，能用在客服和落地頁 FAQ。產品是 [產品]。
```

**23. LINE 自動回覆設定**
```
/hello-hugo 幫我把客服知識庫接上 LINE Bot，讓客戶問問題可以自動回覆。
```

**24. 把見證變成轉換素材**
```
/hello-hugo 這是我收到的客戶見證：[貼上]。幫我把它變成可用的轉換素材——貼文、和落地頁可放的段落。
```

## 🧭 團隊決策與規劃

**26. 一句話講清楚你是誰**
```
/hello-hugo 幫我把「我是誰、幫誰解決什麼問題」濃縮成一句清楚有力的定位句，多給我幾個版本挑。我做的是 [簡述]。
```

**27. 每週進度總覽**
```
/hello-hugo 進度總覽
```

**28. 工具串接優先順序建議**
```
/hello-hugo 看我目前的痛點，幫我排一下接下來該優先接哪些工具（Gmail/Notion/LINE/Vercel...）。
```

**29. 跨角色協作建議**
```
/hello-hugo [做完的某件事] 完成了，接下來還可以請哪個夥伴接手放大成效？
```

**30. 一季自動化藍圖**
```
/hello-hugo 幫我規劃接下來一季要陸續把哪些自動化接起來（排程、串接工具），給我一張看得懂、跟得上的全局圖。我這季的目標是 [目標]。
```

---

> 這 30 個是「食譜」，不是天花板。任何時候你都可以直接用白話跟 Hugo 說你想達成什麼，他會調度對的人幫你完成——食譜只是讓你更快知道「原來可以這樣下指令」。
