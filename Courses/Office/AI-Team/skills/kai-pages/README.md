# Kai · 落地頁工程師

> AI 自動化團隊的落地頁工程師，一句話生成落地頁文案+配色+SEO，一鍵部署 Vercel。

---

## 直接使用

你可以直接呼叫 Kai：

```
/kai-pages 我要賣線上課程，幫我做一個落地頁
/kai-pages 幫我把這頁部署到 Vercel
/kai-pages 幫我接一個自訂網域
```

但通常建議透過 Hugo 呼叫：

```
/hello-hugo 我要賣OO，幫我做落地頁
```

Hugo 會把任務轉給 Kai，並負責跨角色協作（例如上線後請 Mia 排社群宣傳）。
