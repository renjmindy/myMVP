# Workflow：一句話 → 完整落地頁

> Kai 產出落地頁完整結構 + 文案 + 可部署的 HTML 網頁。

---

## 觸發條件

- 「做落地頁」「做 LP」
- 「我要賣 OO，幫我做一個頁面」
- 「銷售頁內容幫我寫」

---

## 執行步驟

### Step 1：確認頁面目的

> 「這個頁面的目的：
> A. 收 Email 名單／預約　B. 直接賣（含金流連結／導購）　C. 報名活動
> 你要賣的是？（產品/服務一句話說明）」

### Step 2：確認關鍵資訊

一次問完：

1. **要承諾用戶什麼**？（你給的東西是什麼）
2. **有沒有時間壓力**？（截止日 / 限額 / 早鳥價）
3. **既有素材**：有沒有照片、影片、見證可以用？
4. **定價**（如果是直接賣）

### Step 3：讀資料

- `~/.claude/skills/_base/business-profile.md`（品牌語氣、目標客群）

`business-profile.md` 是範本 → 一題一題帶用戶填，不要整份丟給他自己寫。

### Step 4：決定配色

> 「品牌色你有指定嗎？沒有的話我給你 3 個方向：
> A. 質感暗調（深色背景、高端氛圍）
> B. 明亮生活（自然光、親切感）
> C. 極簡文字（大字排版、文案驅動）」

### Step 5：產出頁面藍圖（先給全貌）

依 Step 1 的答案套用對應結構（見 SKILL.md 三種場景），列出這頁會有哪些區塊，跟用戶說：

> 「這頁我會這樣排：[區塊清單]。我們一塊一塊做、一塊一塊調，先從 Hero（第一屏）開始，OK 嗎？」

### Step 6：逐區塊產出（核心循環，不要跳過確認）

每個區塊：

1. **寫這塊的文案**（用品牌資料 + 真實賣點，不要 placeholder）
2. **做成有質感的 HTML 區塊**（排版層次、留白、品牌色、字級對比、按鈕樣式）
3. **給用戶看 + 主動問**：
   > 「這是 Hero 區，標題我用『[實際標題]』。你看這個主張對嗎？要更強烈還是更溫和？」
4. 用戶確認 → **接到目前的頁面累積起來** → 做下一塊

**內容模板參考：**

```markdown
## Hero 區（首屏）
主標題（H1）：[強力 Hook，10-15 字內]
副標題：[對誰、解決什麼，20-30 字]
CTA Button：[行動詞，例：立即免費下載 / 馬上加入]

## 痛點共鳴
你是不是這樣？
- [痛點 1，具體場景]
- [痛點 2，具體場景]
- [痛點 3，具體場景]

## 解方介紹
我們做了什麼：[簡述解方，2-3 句]
3 個核心好處：
1. **[好處 1]**：[一句話說明]
2. **[好處 2]**：[一句話說明]
3. **[好處 3]**：[一句話說明]

## 社證
- 「[見證引文]」— [姓名 / 職稱]
- 已幫助 [X] 人達成 [Y]

## 定價 + CTA（若為直接賣）
[價格對比、保證機制、多重 CTA]

## FAQ
Q1：[最常見的疑慮] → A：[解答]
Q2：... → A：...
Q3：... → A：...

## Footer CTA（最後一擊）
[最後一次行動呼籲] + [同 Hero 區的 CTA] + [補充信任語]
```

### Step 7：全部做完 → 合成完整單檔 HTML

- 檢查整頁節奏、區塊間銜接、手機版排版
- 內建 SEO：`<title>`（55 字內含主張）、`<meta name="description">`（155 字內）、Open Graph 標籤（`og:title` / `og:description` / `og:image`）
- 主動問：「整頁看一遍，有沒有哪一塊想再調？」

### Step 8：預覽與下一步

- **想自己先看** → 雙擊 `.html` 檔，瀏覽器就打開
- **要正式上線** → 走 `workflows/vercel-deploy.md`

### Step 9：收尾

記進 `~/.claude/skills/_base/task-log.md`：
```
- 【日期】｜Kai｜完成 [產品名] 落地頁（[目的]）｜[已部署/待部署]
```
