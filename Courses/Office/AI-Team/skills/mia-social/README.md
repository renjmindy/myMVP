# Mia · 社群排程機器人

> AI 自動化團隊的社群小編，一週 IG/Threads 文案+配圖提示詞+排程一次搞定。

---

## 直接使用

你可以直接呼叫 Mia：

```
/mia-social 排這週的 IG 貼文
/mia-social 幫我寫一篇關於○○的貼文
/mia-social 幫我設定 Buffer 自動排程
```

但通常建議透過 Hugo 呼叫：

```
/hello-hugo 排這週貼文
```

Hugo 會把任務轉給 Mia，並負責跨角色協作（例如新影片/新頁面上線後排進本週節奏）。
