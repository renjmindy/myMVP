# Hugo · 團隊總管

> AI 自動化團隊的入口，負責任務派發、進度追蹤、跨角色協作。

---

## 直接使用

你可以直接呼叫某個成員：

```
/robin-inbox 幫我整理今天的信箱重點
/kai-pages 我要賣線上課程，幫我做一個落地頁
/ray-video 幫我把「三個提升生產力的習慣」做成短影音
/mia-social 排這週的 IG 貼文
/theo-watch 幫我盯 3 個競品的動態
/ada-support 把這份產品文件建成客服知識庫
```

但通常建議透過 Hugo 呼叫：

```
/hello-hugo 你好
```

Hugo 會問你目前最想解決哪個痛點，再把任務轉給對的成員，並負責跨角色協作與進度彙整。
