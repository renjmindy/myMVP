# 1.1｜What Is Claude Code: From Chat Tool to Working Agent

## Learning Objectives

- Be able to explain, in one sentence, the fundamental difference between Claude Code and the ChatGPT / Claude.ai chat box;
- Understand the concept of an "Agent": the loop of Perceive → Plan → Execute → Verify;
- Know what Claude Code can actually do for you (not limited to writing code);
- Form a first impression of "permissions and safety," setting up for later chapters.

## Suggested Duration

20–25 minutes

## Course Outline

### 1. From "Chatting" to "Getting Things Done": An Analogy

- Chat tools (ChatGPT / Claude.ai): you ask, it answers, and the answer stays in the chat box — turning it into action (saving files, running code, sending emails) requires you to copy and paste it yourself.
- Claude Code: you assign a task, and it **takes action itself** — reading files, writing files, running commands, running tests, looking things up, calling tools — and when it's done, it reports the results back to you, even checking its own work along the way.
- Analogy: a chat tool is like "a consultant on the phone" who only gives advice; Claude Code is like "a technician who shows up with a toolbox" and just gets the job done.

### 2. The Agent Loop: How an Agent Works

A four-step loop, which can be drawn as a circular diagram:

1. **Understand the goal** (Understand): reads and comprehends your task description, asking clarifying questions when necessary;
2. **Plan the steps** (Plan): breaks the task down into executable sub-tasks; for complex tasks, it will first lay out a to-do list;
3. **Take action** (Act): calls tools — reading and writing files, running terminal commands, searching the web, calling APIs;
4. **Verify the result** (Verify): runs tests, checks output, self-corrects against the goal, and re-plans if the result falls short.

> Key point: this loop happens **automatically and continuously** — you don't need to manually confirm every single step (unless a high-risk operation is involved; see the "Safety" section). This is precisely the dividing line between an "agent" and a "chatbot."

### 3. What Claude Code Can Do (Not Just Write Code)

Real-world scenarios in place of a feature list:

| Scenario | Example Task |
|---|---|
| Software development | "Help me fix this login error bug and run the tests" |
| File organization | "Standardize the naming of these 200 course files in this folder and sort them by chapter" |
| Content creation | "Read these 10 viral articles and summarize the common headline formula" |
| Data processing | "Read this Excel file and generate a visualized weekly sales report" |
| Automation | "Write a script that fetches the exchange rate every morning and emails it to me" |
| Research | "Search the pricing strategies of these 5 competitors and compile them into a comparison table" |

Later chapters of this course will break down each category of scenario in the table above, one by one.

### 4. First Impression: Permissions and Safety (Planting a Thread)

- When Claude Code performs "read" operations, it generally doesn't need confirmation;
- Before performing operations with broader impact — such as "write / delete / execute commands / send data over the network" — it will, by default, **ask you for confirmation**;
- For now, students only need to remember one sentence: "The more capable it is, the more carefully you should look at what it's about to do next before clicking confirm." Specific permission modes will be covered in detail in 1.5 and 1.6.

## Suggested Live Demonstration

Prepare a sample folder containing 10–15 files (can be messily named images or documents), and demonstrate live:

```
> Help me see what's in this folder, and organize it into subfolders by file type
```

Have students focus on observing how Claude first "reads → lists a plan → asks for confirmation → executes → reports the result," rather than jumping straight into action.

## Frequently Asked Questions

**Q: Is Claude Code only for programmers?**
A: No. Its core capability is "understanding tasks + operating on the files and tools on your computer." Programming is just one of many use cases. This course places particular emphasis on non-purely-technical scenarios such as content creation, market research, and office automation.

**Q: Will it delete my files without permission?**
A: Under the default permission mode, operations involving modification/deletion will first ask for your confirmation. The specific permission tiers will be covered in detail in later lessons.

**Q: What's the difference from pasting code into the ChatGPT web version?**
A: The ChatGPT web version gives you "text suggestions" — you need to copy, paste, run, and debug them yourself. Claude Code carries out this entire sequence of actions directly on your computer, and can independently handle complex, multi-step, cross-file tasks.
