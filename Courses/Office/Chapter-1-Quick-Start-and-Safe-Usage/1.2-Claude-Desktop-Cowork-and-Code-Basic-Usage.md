# 1.2｜Claude Desktop Cowork and Code Basic Usage

## Learning Objectives

- Get familiar with the basic interface and core areas of the Claude desktop client (Claude Desktop);
- Understand the difference in positioning between Cowork (the collaborative workspace) and Claude Code (the command-line agent);
- Be able to independently complete: starting a new conversation, uploading files, creating a Project, and using Artifacts to preview results;
- Know "which tasks call for Desktop and which call for the CLI."

## Suggested Duration

25 minutes

## Prerequisite Knowledge

- Have completed 1.1 and understand the concept of an "agent."

## Course Outline

### 1. Claude Desktop Interface Tour

Walk students through the following areas one by one (screenshots or annotated screen recordings recommended):

1. **Conversation list**: the entry point for past sessions — searchable, pinnable, and archivable;
2. **Main conversation area**: the input box supports text, drag-and-drop files, and pasted images;
3. **Model selector**: switch between different model tiers such as Sonnet / Opus / Haiku;
4. **Projects entry point**: covered in detail in 2.3 — just build a first impression here;
5. **Artifacts panel**: when Claude generates a web page, chart, or document, it renders a preview in a separate panel on the right, rather than getting buried in the chat text.

### 2. What Is Cowork

- Cowork is the form of workspace within Claude Desktop designed for "multi-file, multi-step collaborative tasks." Think of it as "a workbench built around a specific project," rather than a single round of Q&A.
- Core characteristics:
  - You can designate a set of files/data as the scope of the work;
  - Supports task decomposition and progress tracking;
  - Supports human-AI handoff: the AI does part of the work, and after you confirm or add to it, it continues.
- Typical use cases: organizing a batch of contracts/documents, producing a market research report, batch-processing spreadsheet data (covered hands-on in Chapter 4).

### 3. Cowork vs. Claude Code: How to Choose

| Dimension | Claude Desktop / Cowork | Claude Code CLI |
|---|---|---|
| Execution environment | Graphical interface, mainly mouse-driven | Command-line terminal, mainly keyboard-driven |
| Suitable tasks | Document organization, data research, visualization output | Code development, automation scripts, system-level operations |
| File operation capability | Relies on upload/drag-and-drop, limited OS-level permissions | Directly reads and writes real files and directories on your computer |
| Programmability | Weaker, leans toward "task conversation" | Strong — can execute arbitrary terminal commands and run scripts |
| Suited for | Non-technical backgrounds, mainly office scenarios | People who need to work in a terminal / write code / build automation |

> A one-line way to remember it: "If you need to produce a report or organize data, use Cowork; if you need to touch the file system on your computer, run scripts, or build automation, use Code." The two aren't mutually exclusive — many workflows involve "Cowork produces the plan, Code carries it out."

### 4. Basic Operations Hands-On (Follow Along)

1. Start a new conversation and upload 2–3 sample files (PDF / Excel / image, your choice);
2. Have Claude summarize the core content of these files;
3. Ask it to "generate a simple HTML summary page," and observe how the Artifacts panel independently renders this web page, rather than dumping the code into the chat history;
4. Try adding a second task within the same conversation, and observe how it makes use of the file context it already read.

## Frequently Asked Questions

**Q: Are Cowork and Projects the same thing?**
A: Not exactly. Projects lean more toward a "long-term knowledge base + background context" container (covered in detail in 2.3), while Cowork leans more toward a workbench for "the collaborative task at hand." The two can be used together: put long-term reference material into a Project, and put a specific one-off task into Cowork.

**Q: Where are the web pages/files generated by the Artifacts panel stored?**
A: By default they are stored in Anthropic's cloud, tied to the conversation. If you need them to live on your local file system for long-term use, you'll typically need to export them, or use Claude Code CLI instead to generate the files locally.

Using Claude Desktop, upload a piece of real data you have on hand (even just a single article), ask it to generate a summary web page with a title, key points, and a conclusion, and observe how the Artifacts panel renders it. Note down what you found useful and what you didn't.
