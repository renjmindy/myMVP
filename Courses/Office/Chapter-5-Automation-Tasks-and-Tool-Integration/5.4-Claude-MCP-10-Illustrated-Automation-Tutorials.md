# 5.4 | Claude-MCP: 10 Illustrated Automation Tutorials

## Learning Objectives

- Build a broad awareness of MCP use cases through 10 concrete examples;
- Be able to extract transferable integration approaches from these cases that apply to your own scenarios;
- Clarify that this lesson is positioned as a "case map" — learners can dig deeper into any specific application category on their own after class.

## Suggested Duration

30 minutes (case walkthrough, moving through cases at a fast pace without deep-diving into each one)

## Prerequisites

- Have completed 5.2 and 5.3, and understand the basic operation and principles of MCP.

## Course Outline

### I. Positioning and How to Use This Lesson

- Unlike the "deep dive into one case" approach of 5.2/5.3, this lesson moves through 10 cases at a fast pace, with the goal of **broadening horizons** — showing just how wide a range of scenarios MCP can connect to;
- Each case only needs to cover "what problem it solves, roughly how it's connected, and what the effect is" — it won't walk through configuration details line by line. Those details are left to the accompanying illustrated materials (in the course resource library) for learners to consult on their own after class;
- Instructors need to verify before class whether the MCP Servers referenced in the following cases are still available and how active their communities are, adjusting the specific case list based on actual conditions.

### II. Quick Overview of 10 Cases (Presented by Category)

**Data and Knowledge**
1. Connecting to the local file system — batch reading/writing and searching local documents (echoing the automation upgrade of the file-organization scenario from Chapter 4)
2. Connecting to a web browsing/scraping tool — automatically fetching the latest content from a specified webpage
3. Connecting to a database — directly querying/updating structured data using natural language

**Office Collaboration**
4. Connecting to Feishu — automatically reading/writing documents and sending messages (echoing the connection scenario from 4.7, this lesson revisits it from the "protocol layer" rather than the "application layer")
5. Connecting to Google services (Sheets / Calendar, etc.) — automating schedule and spreadsheet handling
6. Connecting to project management tools (such as Notion, Jira-type tools) — automatically creating/updating task cards

**Development and Engineering**
7. Connecting to code repositories (such as GitHub) — automatically viewing/managing code changes and Issues
8. Connecting to design tools — retrieving design file information for front-end implementation (echoing the `DesignSync`-type capability direction in the course resource library)

**Marketing and Growth**
9. Connecting to social media management tools — automatically pulling account data and assisting with content scheduling
10. Connecting to email services — automating email sending and processing (echoing one of the practical application scenarios of "Vercel Cron running scripts automatically" in Chapter 6)

### III. The Common Pattern Behind the Cases (Closing Synthesis)

Work through the synthesis together with learners — these 10 cases all actually follow the same pattern:

```
Identify an external tool scenario that is "manually cumbersome and relatively standardized in logic"
  → Check whether a corresponding MCP Server already exists (community/official)
    → Evaluate its trustworthiness and permission scope (echoing the 5.3 evaluation checklist)
      → Install, verify, and actually integrate it into your workflow
```

- Emphasize that "you don't need to memorize the operational details of these 10 specific cases" — what you need to remember is this general methodology. When you encounter any new scenario in the future, you can use the same approach to find and evaluate a corresponding MCP Server.

### IV. Class Interaction: Find a Case That Matches Your Scenario

Have learners pair up and discuss: does your own work have needs similar to any of these 10 cases? If there's no directly corresponding case, how could you use the evaluation approach learned in 5.3 to find a solution?

## Frequently Asked Questions

**Q: Where can I find the detailed steps for these 10 cases?**
A: The detailed illustrated steps are collected in the corresponding illustrated tutorial package in the course resource library, and will continue to be maintained as the MCP ecosystem evolves. Class time focuses on building breadth of awareness — the details are for you to consult and practice on your own.

**Q: What if the scenario I need isn't among these 10 cases?**
A: Use the evaluation method learned in 5.3 to search for a corresponding MCP Server on your own. If there truly isn't a ready-made solution, you can also consider the "write your own script" path learned in 5.1 — the two paths complement each other.

## Homework

Choose 1–2 cases from the 10 that are most relevant to your own work, and actually carry them out following the illustrated tutorials in the course resource library, recording any problems encountered during integration and how you resolved them.
