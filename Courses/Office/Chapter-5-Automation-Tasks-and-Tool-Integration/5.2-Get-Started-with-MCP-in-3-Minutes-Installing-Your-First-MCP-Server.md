# 5.2 | Get Started with MCP in 3 Minutes: Installing Your First MCP Server

## Learning Objectives

- Complete your first MCP Server installation and invocation via the shortest possible path, building a successful experience;
- Develop an intuitive impression that an MCP Server is a "concrete plugin that connects an external capability";
- Lay the groundwork for the principles explained in 5.3 (learn to use it first, understand the principles later).

## Suggested Duration

20 minutes (guided hands-on, deliberately compressing the lecture portion to emphasize a fast, successful experience)

## Prerequisites

- Have completed 2.4 (an initial impression of the MCP concept: "a universal connector fitted for the craftsman").

## Course Outline

### I. Opening: Skip the Theory, Get Hands-On Right Away

- This lesson deliberately takes a counterintuitive "act first, understand later" approach, with the goal of quickly building a successful experience and lowering the intimidation that the seemingly "highly technical" concept of MCP can create;
- 5.3 will fill in the complete explanation of the principles — for this lesson, just follow along.

### II. Choosing a Beginner-Friendly MCP Server

It's recommended to choose an MCP Server with zero external account dependencies and an intuitive effect as the teaching example (such as a file-system type or a time/date type basic utility MCP Server). The specific choice should be verified by the instructor before class as the most stable, easiest-to-install option in the current ecosystem.

### III. 3-Minute Installation Process (example structure — instructors should verify and update against current actual commands)

**Step 1: View currently connected MCP Servers**

```
/mcp
```

**Step 2: Add a new MCP Server**

```bash
claude mcp add <server-name> <command>
```

Or follow the specific installation method provided in the official documentation (installation commands may differ between MCP Servers — always defer to the official instructions for the specific Server in question).

**Step 3: Verify the connection**

```
/mcp
```

Confirm that the newly added Server's status shows as connected.

**Step 4: Test with an actual invocation**

Have Claude use this newly connected tool capability with a single instruction, and observe whether the invocation succeeds (for example, if you installed a file-system type Server, you could test something like "help me look at a file outside a certain directory" — an operation that was previously restricted).

### IV. Celebrate Your First Success — Then Ask "What Just Happened Behind the Scenes"

- Guide learners to observe: something Claude couldn't do before the installation, it can now do after — this is the intuitive value of MCP;
- Pose a cliffhanger question to be answered in 5.3: "How does Claude know this new tool exists? How did it 'learn' to use it?" Use this to draw learners into the next lesson's explanation of the underlying principles with curiosity.

### V. Quick Troubleshooting for Common Installation Issues

| Symptom | Quick Check |
|---|---|
| Add command errors out | Check the command spelling, and check whether the MCP Server requires additional dependencies to be pre-installed |
| `/mcp` doesn't show the newly added Server | Check whether Claude Code needs to be restarted for the configuration to take effect |
| Invocation says the tool is unavailable | Check whether the credentials/service corresponding to that Server are configured correctly |

## Frequently Asked Questions

**Q: Do all MCP Servers cost money?**
A: Not necessarily — many MCP Servers are free, open-source utility plugins (such as local file operations or time handling), while some Servers that connect to commercial services may depend on that service's own pricing policy. It varies by Server.

**Q: What if I installed the wrong thing / no longer want to use it — how do I uninstall it?**
A: Simply remove it via `claude mcp remove <server-name>` or the corresponding management command. This leaves no residual effect on your system, so feel free to experiment.
