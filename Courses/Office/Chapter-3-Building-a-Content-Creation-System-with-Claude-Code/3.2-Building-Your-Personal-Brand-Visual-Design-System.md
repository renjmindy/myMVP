# 3.2 | Building Your Personal Brand Visual Design System

## Learning Objectives

- Understand why "visual consistency" is just as important as a "written persona";
- Master the core elements a visual design system should include: color palette, typography, layout, and material style;
- Use Claude Code to generate a reusable visual design specification document;
- Enable AI to automatically follow this specification when generating subsequent graphic/web content.

## Suggested Duration

30 minutes

## Prerequisites

- Have completed 3.1 (Personal Content Context) — this lesson is the "visual version" extension of that work.

## Course Outline

### I. Why You Need a Visual Design System

- Pain point: Even with a unified written persona, if the color palette and style of every generated image, cover, or page differ each time, the account still lacks distinctiveness and looks unprofessional;
- Solution: Just as writing needs "tone guidelines," visuals need "design guidelines." Once written into a document, it can be referenced directly every time you have AI generate visual content (cover images, Artifacts web pages, sales pages, etc.);
- This system will be directly reused in Chapter 6 when building landing pages and sales pages — it's a long-term asset, not a one-off exercise.

### II. Core Elements of a Visual Design System

**1. Color Palette**
- Primary color, secondary color, accent color (give specific color values rather than vague descriptions like "blue-ish");
- Notes on usage scenarios (primary color for title backgrounds, accent color for buttons/highlights, etc.).

**2. Typography Guidelines**
- Which fonts to use for Chinese/English/numerals respectively (if you have the ability to specify this);
- The font-size hierarchy relationship between headings, body text, and captions.

**3. Layout and Composition Habits**
- Commonly used layout structures (e.g., a fixed pattern of "large headline + three key takeaways + illustration");
- Whitespace habits and alignment preferences.

**4. Material and Image Style**
- Photography style vs. illustration style vs. minimalist graphic style;
- Whether to feature real people on camera, whether to use specific filters/stylized processing;
- Icon style (linear/filled/rounded corners/sharp corners).

### III. Hands-On: Building From Scratch or Reverse-Engineering From Existing Content

**Path A: You already have an account — reverse-engineer the guidelines from historical materials**

1. Put 5–10 representative images/covers you've previously published into `assets/historical-visual-assets/`;
2. Enter:

```
> Please look at the images in assets/historical-visual-assets/ and help me summarize the common color tendencies, composition habits, and overall visual style, giving specific color-value references wherever possible
```

3. Compare against the summary point by point and correct any misjudgments the AI may have made (the AI's color-value judgments are for reference only — for important use cases, use a color-picker tool to double-check).

**Path B: A brand-new account — design forward from your target style**

1. Describe the feeling you want to convey (e.g., "professional but not cold, leaning toward Japanese-style minimalism");
2. Provide 1–2 descriptions of reference styles you like (not copying someone else's materials directly, but describing the style characteristics);
3. Have Claude propose a set of color/typography/layout recommendations for you to choose from and adjust.

### IV. Compiling the Design System Document

Compile everything into `docs/visual-design-system.md`. Suggested structure:

```markdown
# Visual Design System

## Color Palette
- Primary: #XXXXXX (usage)
- Secondary: #XXXXXX (usage)
- Accent: #XXXXXX (usage)

## Typography Guidelines
- Heading font / size
- Body font / size

## Layout Habits
- Description of commonly used layout structure

## Material Style
- Description of image/illustration style
- Restrictions (e.g., avoid a certain type of filter, avoid a certain font)
```

> Instructor note: You can connect this to the `dataviz`-type skill concepts in the course resource library, emphasizing that "a design system doesn't limit creativity — it raises the starting point of every output and saves time on back-and-forth revisions."

### V. Validating the Effect

Have Claude generate a sample Artifact based on this design system (e.g., a simple graphic-and-text card web page), and check whether it follows the color and layout guidelines. Where it doesn't, go back and refine the precision of the document's descriptions (the more specific, the better AI will follow it).

## Frequently Asked Questions

**Q: I don't have a design background — can I still set my own guidelines?**
A: You can start from intuitive judgments like "what I like/don't like" — no professional design theory required. AI can help translate your intuition into specific color values and layout recommendations; your job is to choose and confirm the direction.

**Q: Once the visual system is set, can it never change?**
A: It can evolve, but frequent major overhauls aren't recommended — the value of visual consistency lies precisely in "sustained uniformity." It's better to accumulate a certain volume of content before making systematic adjustments, rather than changing it every time.
