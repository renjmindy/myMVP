# Chapter 3 | Building a Content Creation System with Claude Code

## Chapter Positioning

Chapters 1 and 2 laid the foundation of tools and workspace. Chapter 3 begins the course's first complete hands-on theme: **turning Claude Code into your content creation system**, aimed at content creators, brand operators, and content marketing practitioners.

By the end of this chapter, learners should be able to:

1. Build a reusable "Personal Content Context" for themselves (persona, tone, content history, material library);
2. Build a personal brand visual design system so that AI-generated visual content stays stylistically consistent;
3. Use Claude Code to conduct market research and identify real content demand and topic opportunities;
4. Master methods for analyzing viral content, outlier data, and benchmark accounts, building a complete "topic selection → validation → production" loop.

This chapter is the first hands-on test of the "workspace and context management" skills from Chapter 2 — learners will produce a full set of reusable content production assets around their own real content account/brand, rather than a one-off exercise.

## Lesson Schedule (Suggested)

| Lesson | Title | Suggested Duration | Format |

The whole chapter runs about 2 hours in total, recommended to be delivered across 2 class sessions, each covering 2 lessons.

## Learner Prerequisites

- Have completed Chapters 1 and 2, and can proficiently use the workspace, CLAUDE.md, and Projects;
- Have a real or planned content account/brand (a personal media account, official account, Xiaohongshu, or a company's official account are all fine) — the whole chapter is built around this one real subject, avoiding practice in a vacuum;
- Recommended to prepare in advance: at least 5–10 pieces of content you've previously published (for building your content context), along with a list of 3–5 benchmark accounts in the same niche.

## Chapter Deliverables / Success Criteria

After completing this chapter, learners should produce:

- [ ] A complete "Personal Content Context" document (persona, tone, content history summary, do-not list);
- [ ] A visual design system document (color palette, typography, layout guidelines that AI can follow when generating content);
- [ ] A market research report containing at least 3 actionable topic directions;
- [ ] A benchmark analysis report containing a summary of viral-content patterns from at least 3 benchmark accounts.

## Instructor Notes

- This chapter emphasizes "practicing with your own real account." Instructors should remind learners before class to prepare materials, to avoid a situation where, lacking materials in class, they can only use sample data — which would reduce learning effectiveness;
- Sections 3.3 and 3.4 involve online search/scraping-type operations. Instructors need to explain in advance the boundaries of compliant data usage (not infringing copyright, not using it for harassment-type information gathering);
- The content context and visual system produced in this chapter will be directly reused in Chapter 6, "Website and Sales Page Delivery." Instructors can preview this continuity in advance to increase learners' motivation to produce quality output.
